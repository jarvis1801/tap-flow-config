Privacy Policy

Effective Date: November 19, 2026 • App: TapFlow (com.jarvis.tapflow)

Privacy at a Glance: TapFlow requires no user account, contains no ads or behavioral tracking, and executes all automation, color/image matching, and script storage 100% locally on your device. Network access is used strictly for Google Play Billing and optional promo-code verification via Firebase Remote Config.

1. Information Stored Locally on Your Device

TapFlow operates on an offline-first architecture. All automation data you create or capture remains inside your device's private application storage unless you explicitly export it:

  • Scripts, Pipelines & Variables: Automation sequences, timing settings, and variable definitions stored in a local Room/SQLite database.
  • Inspect Screenshots & Pixel Targets: Lossless PNG screenshots, sampled pixel coordinates/colors, and crop region bounds captured when you intentionally use Live Recording, Live Inspect, or Screenshot Import.
  • Execution Logs & Failure Snapshots: Local execution history and optional failure screenshots stored temporarily on-device (automatically pruned to recent sessions / 7 days).
  • App Preferences & Entitlement Anchors: UI settings (theme, language, overlay size), local 7-day trial timestamps, and redeemed promo window timestamps protected using Android Keystore cryptographic HMAC verification to prevent tampering.
  • Manual .tapflow Backups: When you export a .tapflow backup file via Android's system file picker, only script/pipeline configurations are exported (screenshots and Inspect assets are strictly excluded).

2. Sensitive Android Permissions & How They Are Used

TapFlow only requests system permissions essential to user-initiated automation features:

AccessibilityService API

  • Purpose: Used exclusively to dispatch user-configured touch gestures (tap, double tap, long press, multi-touch, swipe), trigger system navigation actions (Home, Back, Recents, etc.), insert text into focused fields you configure, detect the active foreground app package name for App Match rules and Inspect metadata, and optionally intercept hardware Volume Down presses if you enable Emergency Stop.
  • Strict Non-Collection Guarantee: TapFlow never uses the AccessibilityService API to collect, harvest, log remotely, sell, or transmit screen contents, keystrokes, passwords, messages, or personal information.

Screen Capture (MediaProjection)

  • Purpose: Used only when you run scripts containing Color Match or Image Match conditions, or when you actively start Live Recording or Live Inspect. Frames are analyzed in memory on-device (or saved locally in private storage for Inspect/failure logs) and are never uploaded or streamed to external servers.

Display Over Other Apps (SYSTEM_ALERT_WINDOW)

  • Purpose: Displays the floating control dock, coordinate picker, and optional visual touch debug marker over other apps while you operate or test scripts.

Installed Applications Visibility

  • Purpose: Queries launchable apps locally on your device solely so you can pick target apps inside Launch App, Force Stop App, and App Match actions, and display app icons/names on Inspect items. Your installed app list is never sent off your device.

Optional System Integrations (Shizuku, MacroDroid & Tasker)

  • If you choose to grant permission via Shizuku or send local Android broadcasts from MacroDroid or Tasker, commands execute locally on-device. TapFlow does not transmit data to third-party automation apps outside the local broadcast status extras you trigger.

3. Network Requests & Third-Party Services

While TapFlow's core automation runs completely offline, limited network communication occurs strictly for licensing and optional promo verification:

  • Google Play Billing: In-app purchases and purchase restoration are processed directly by Google Play. TapFlow receives only purchase tokens/entitlement status and never accesses or stores your credit card or banking details. See the Google Privacy Policy.
  • Firebase Remote Config (Optional Promo Codes): When you manually submit a promo/redeem code on the upgrade screen (or during periodic config refresh), TapFlow connects to Firebase Remote Config to verify code validity and date windows. Firebase Installations uses an ephemeral app-instance identifier solely to deliver Remote Config parameters. TapFlow does not use Google Analytics for Firebase for ad personalization or user profiling. See Firebase Privacy & Security.

4. Data Control, Retention & Deletion

  • You have full control over your local data: you can delete individual scripts, pipelines, Inspect groups, or execution logs, or clear all cached Inspect images inside Settings.
  • Execution logs and associated crash screenshots are automatically pruned under TapFlow's local retention policy (maximum 50 sessions or 7 days).
  • Uninstalling TapFlow permanently removes all private local databases, preferences, and saved screenshots from your device (excluding any .tapflow backup files you manually saved elsewhere).

5. Children's Privacy

TapFlow is a general utility application and is not directed at children under the age of 13 (or the minimum legal age in your jurisdiction). Because we do not collect personal accounts or analytics, we do not knowingly collect personal data from children.
